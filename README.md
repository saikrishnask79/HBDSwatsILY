# Happy Birthday, Swats

A personal birthday page with a memory lane, romantic messages, and a framed floral portrait.

## Publish with GitHub Pages

1. Open the repository on GitHub and choose **Settings**.
2. In the sidebar, open **Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then select **Save**.
5. Wait for the Pages deployment to finish. The site will be available at https://saikrishnask79.github.io/HBDSwatsILY/.

The site's `index.html` is in the repository root, and its images and scripts use relative paths.
